Tutorial 9: Counterfactual Analysis and Bayesian Forecasting

Continuous predictions, new dosing schedules, and individualising treatment

Introduction

A fitted DCM is not just a description of the training data — it is a generative model that can answer clinical "what-if" questions:

  • What concentration–time profile would this patient have on 200 mg instead of 100 mg?
  • Is once-daily or twice-daily dosing better for achieving the target exposure?
  • Given two early measurements, what dose should I give next?

This tutorial covers three closely related workflows:

  1. Continuous predictions — generating smooth concentration–time curves at any time grid, including between and after observed time points.
  2. Counterfactual dosing — changing the dosing callback to evaluate alternative treatment schedules.
  3. Bayesian forecasting — using a population-fitted model as a prior to individualise predictions when only a few observations are available (therapeutic drug monitoring, TDM).

using DeepCompartmentModels

We reuse the tobramycin model from Tutorial 8. For brevity, the loading and fitting steps are condensed here.

function load_tobramycin(df, ::Type{T} = Float32) where T
    duration = T(40/60)
    df_group = groupby(df, :ID)
    indvs = Vector{AbstractIndividual}(undef, length(df_group))
    for (i, group) in enumerate(df_group)
        x   = Vector{T}(group[1, [:WT, :AGE, :SEX, :CLCR]])
        obs = group[iszero.(group.EVID), [:TIME, :CP]]
        d   = Matrix{T}(group[group.EVID .== 1, [:TIME, :DOSE]])
        I   = hcat(d, d[:, 2] ./ duration, fill(duration, size(d, 1)))
        cb  = generate_dosing_callback(I, T)
        indvs[i] = Individual(group.ID[1], x, Vector{T}(obs.TIME),
                              Vector{T}(obs.CP), cb, T)
    end
    Population(indvs)
end

Part 1 — Continuous predictions

By default, predict returns concentrations only at the individual's observation time points (get_t(indv)). Pass a dense saveat grid to get a smooth curve at any desired resolution.

indv = population[1]

# `ps` holds the random effects of all individuals, `take_batch` selects those of one
ps_indv, st_indv = take_batch(ps, st, [1])

# Sparse: only at observed time points
ŷ_sparse = predict(model, indv, ps_indv, st_indv; saveat=get_t(indv))

# Dense: every 30 minutes
t_dense = Float32.(0:0.5:maximum(get_t(indv)) + 24)
ŷ_dense = predict(model, indv, ps_indv, st_indv; saveat=t_dense)

fig = Figure(size=(650, 350))

Part 2 — Counterfactual dosing

To evaluate a different dosing regimen, create a new DiscreteCallback with generate_dosing_callback and swap it into a copy of the existing individual using copy(indv, new_callback). The individual's covariates and random effects stay the same — only the dosing changes.

Building a new dosing schedule

# Helper: build a dosing matrix for repeated IV infusions
# doses: [time, amount] pairs; duration in hours
function iv_regimen(times, amounts, duration::T) where T
    rates = amounts ./ duration
    durs  = fill(T(duration), length(times))
    return hcat(T.(times), T.(amounts), T.(rates), T.(durs))
end

Population counterfactual: exposure distribution across regimens

Comparing AUC and Cmax distributions across the whole population shows which regimen achieves the best target attainment.

function auc_and_cmax(pred_vals, t_grid)
    # Trapezoidal AUC over the last 24 h
    last_24 = t_grid .>= (maximum(t_grid) - 24)
    t24 = t_grid[last_24]
    c24 = pred_vals[last_24]
    auc  = sum((c24[1:end-1] .+ c24[2:end]) ./ 2 .* diff(t24))
    cmax = maximum(pred_vals)
    return auc, cmax
end

    ŷ_b   = predict(model, copy(subj, cb_b), ps_i, st_i; saveat=t_eval)

Part 3 — Bayesian forecasting (TDM)

In therapeutic drug monitoring, a new patient arrives with known covariates and one or two measured concentrations. The goal is to update our prediction of their PK parameters and recommend an appropriate dose.

With VariationalELBO, the fitted ps.theta (neural network) and ps.omega (prior on random effects) encode population knowledge. For a new patient, we only need to find their individual random effects φᵢ = (μᵢ, Lᵢ).

Step 3 — Optimise only φᵢ, keeping θ and Ω fixed

function fit_individual_phi(obj, model, indv_pop, ps, st; epochs=400, lr=5f-3)
    opt_phi = Optimisers.setup(Optimisers.Adam(lr), ps.phi)
    for epoch in 1:epochs
        # Update epsilon samples (reparameterisation noise)
        st = update_state(st, obj, model, indv_pop, ps)

        # Gradient of the negative ELBO (with the path derivative estimator, since `obj` uses it)
        loss, ∇ = value_and_gradient(obj, model, indv_pop, ps, st)
        opt_phi, new_phi = Optimisers.update(opt_phi, ps.phi, ∇.phi)
        ps = @set ps.phi = new_phi
    end
    return ps, st
end

Step 5 — Dose recommendation

Given the posterior prediction, we can find the dose that achieves a target AUC:

# Target AUC₀₋₂₄ = 80 mg·h/L (a typical aminoglycoside PK/PD target)
target_auc = 80f0
t_24 = Float32.(0:0.5:24)

function predicted_auc(dose, new_patient, ps, st, duration=40f0/60f0)
    A_d  = iv_regimen([0], [dose], duration)
    cb_d = generate_dosing_callback(A_d, Float32)
    ŷ_d  = predict(model, copy(new_patient, cb_d), ps, st; saveat=t_24)
    return sum((ŷ_d[1:end-1] .+ ŷ_d[2:end]) ./ 2 .* diff(t_24))
end

# Grid search over doses (in practice, a proper optimiser would be used)
dose_range = Float32.(40:5:200)
aucs_pred  = [predicted_auc(d, new_patient, ps_tdm, st_tdm) for d in dose_range]

optimal_dose = dose_range[argmin(abs.(aucs_pred .- target_auc))]
println("Recommended dose to achieve AUC = $target_auc mg·h/L: $(optimal_dose) mg")
