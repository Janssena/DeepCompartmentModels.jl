Status and limitations

The tutorials only use features that work in the current source, and every example on this site is executed when the documentation is built. While preparing them, several parts of the interface turned out not to work. They are listed here so that nobody has to rediscover them. Each entry gives the symptom and the cause found in the source, to make fixing them quick.

Training loop

fit runs the training loop (setup, gradient, Optimisers.update). It supports the fixed effect objectives (MSE, SSE, LogLikelihood) and VariationalELBO, see the entries below for the exceptions. The tutorials write the loop out explicitly, because that shows what each step does; fit does the same.

Rough edges

  • Combine(1 => [1], 2 => [2]), the form shown in its docstring, fails with a MethodError: the pairs are passed on as a tuple instead of being splatted. Use the form with the output dimension, Combine(2, 1 => [1], 2 => [2]).
  • SingleHeadedBranch and MultiHeadedBranch default to activation = swish, which is not in scope inside the package. Always pass activation = Lux.swish (or another activation).
  • softplus and tanh are not re-exported, use Lux.softplus. (Julia's own tanh is fine.)
  • A branch that feeds k outputs of Combine must have k output rows, so use MultiHeadedBranch(idx, neurons, k).
  • The time span of an ODEProblem has to start before the first dose (the default of DCM(ode_fn, ...) is -0.1), otherwise a dose at t = 0 is silently never given and all predictions are zero.
  • For a UniversalDiffEq with at least 512 parameters the default sensealg is GaussAdjoint(; autojacvec = ReverseDiffVJP(false)), which is much faster than forward sensitivities for large networks (5x at ~1,000 and 50x at ~4,000 parameters). Its gradients differ from the forward ones by ~2e-4 (relative), and Lux logs a one-time warning about ReverseDiff.TrackedReal inputs. Pass sensealg = ForwardDiffSensitivity() to use forward sensitivities regardless of the size. Do not use ReverseDiffVJP(true) (compiled tape) with in-place UDEs: it returned a wrong gradient in a test. InterpolatingAdjoint(; autojacvec = EnzymeVJP()) is another 1.5-2.5x faster and gave correct gradients, at the cost of a longer compilation.
  • The ODE solver logs a dt_epsilon warning for every solve when the initial state is zero. Setting an initial step with ODEProblem(...; dt = 0.01f0) avoids thousands of warnings during training.
  • make_etas is exported but not defined.
  • predict(model, individual, ps, st) for a single individual needs the parameters of that individual only. When ps holds the random effects of a whole population, select them with ps_i, st_i = take_batch(ps, st, [i]) (an ArgumentError explains this otherwise), as in the mixed-effects tutorial.
  • target defaults to 1. For models with an absorption compartment the observed concentration is state 2, so set target = 2.
  • Many exported functions have no docstring yet (see the API reference).
  • UniversalDiffEq models only support the fixed effect objectives (MSE, SSE, LogLikelihood), not VariationalELBO.
  • Five test files in test/lib (objectives, initializers, mixed_effects, model, dcm) refer to an older interface (make_etas, init_omega, forward_ode, ...) and do not run against the current source. They are skipped by runtests.jl unless DCM_LEGACY_TESTS=true.
